Read and follow the instruction documents in this file before working in this repository.
All paths are relative to the repository root.

Which sections to read:

- **Always**: General, Agents and Code.
- **Kotlin project** (`settings.gradle.kts` or `build.gradle.kts` at the root): Kotlin.
- **Rust project** (`Cargo.toml` at the root): Rust.
- **Both languages in one repository**: Kotlin and Rust.
- **XML files in the task** (`.xml`): XML.

Read every document of a section in full before the first edit. The Code, Kotlin, Rust and
XML sections also load on their own with a matching file you read or edit; that does not replace
reading them here first. A new document goes into one of these lists and keeps its group's suffix
(`.kt.md`, `.rs.md`).
